I want to demonstrate my interest and knowledge of LLMs and Machine Learning. At the same time, I want to demonstrate my learning process of C++ for production code and CUDA programming.

Over these next few weeks, I will follow the general Claude plan I generated and learn about CUDA, LLM programming, etc.
